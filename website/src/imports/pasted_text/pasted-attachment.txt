## QuickPress — Homepage Figma Design Prompt

Design a **premium, modern, high-conversion corporate startup homepage for “QuickPress”**, an information-focused website for a modern on-demand services and delivery platform.

### Design Inspiration

Take **Pronto-style modern startup website design inspiration** — especially its clean layout, strong typography, spacious sections, modern cards, smooth transitions, premium SaaS/startup feel and simple navigation.

**Do NOT copy Pronto’s exact layout, text, graphics, illustrations, branding or components.** Use it only as visual inspiration and create a completely original QuickPress design.

### Brand Style

* Background: **Pure White**
* Primary text: **Black / near-black**
* Primary brand color: **QuickPress Green**
* Secondary accent: **Yellow**, used selectively
* Clean premium typography
* Large bold headings
* Generous whitespace
* Minimal borders
* Soft rounded cards
* Subtle shadows only where required
* Modern professional startup appearance
* Avoid excessive gradients
* Avoid a generic AI-generated website look
* The final design should look like it was created by a professional product/UI design agency.

# UI / UX REQUIREMENTS

Create the complete homepage as a **high-fidelity Figma desktop design**, approximately **1440px wide**.

Also create responsive versions for:

* Desktop: 1440px
* Tablet: 768px
* Mobile: 390px

Use:

* 12-column desktop grid
* Consistent 8px spacing system
* Auto Layout
* Reusable components
* Component variants
* Proper typography hierarchy
* Responsive constraints
* Consistent button states
* Hover states
* Smooth micro-interactions

### Animation Direction

Design the UI so it can later support:

* Hero floating-card animation
* Smooth section reveal
* Card hover movement
* Button hover animation
* Number/stat fade-in
* Process-line animation
* Ecosystem connection animation
* Subtle navbar transition on scroll

Animations should feel **premium and restrained**, not flashy.

### Important

The website must feel like a **real technology company website**, not an AI template.

Use **Pronto as inspiration for the overall premium startup feel**, but create a completely original QuickPress visual identity, layout, copy, graphics and components.

The final Figma homepage should look suitable for an actual company launch and should be developer-ready.
